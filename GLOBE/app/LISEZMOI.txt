Place ici la version Web de l'application :

1. Genere le build : flutter build web --release
2. Copie TOUT le contenu de build\web\ dans CE dossier (app/)
   -> app/index.html, app/main.dart.js, app/assets/, etc.

Le bouton "Ouvrir l'app Web" de la page pointe deja vers ./app/

IMPORTANT : avant le build, mets l'URL publique de ton backend dans
lib/core/constants.dart (prodUrl) sinon l'app web ne pourra pas
contacter l'API.
